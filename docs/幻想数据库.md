# 幻想数据库网页

“幻想数据库”是 dispatch 内嵌的本地查询和 GM 工作台，入口为 `http://127.0.0.1:8088/fantasy-db/`。根路径 `/` 也会跳转到该页面。

## 从控制器打开

在服务端控制器点击“打开数据库网页”。控制器会先启动或确认其 PostgreSQL 容器，再检查数据库是否为空；如果为空，会构建迁移程序并执行 `server/migrations/000000_init-N.sql` 初始化分片。随后控制器会启动或重连 dispatch，确认目录接口可用后，用系统默认浏览器打开本机页面。这个操作不会启动游戏服。

控制器和命令行共用 `server/docker-compose.yml` 及可选的 `server/.env`。数据库容器为 `fantasy-postgres`，数据卷为 `fantasy-postgres-data`，默认端口 `5432`，用户和数据库名均为 `fantasy`。停止数据库会保留数据卷；控制器只对空库自动执行初始化。

也可自行启动 dispatch，然后在本机浏览器打开上述地址。dispatch 默认监听 `:8088`；如只供本机使用，可显式绑定 `-addr 127.0.0.1:8088`。使用独立 PostgreSQL 时，通过 `DATABASE_URL` 或 `-dsn` 指定连接串。使用仓库提供的 Compose 命令启动时，控制器会识别同一个数据库容器。连接其他 PostgreSQL 实例时，通过命令行传入对应连接串；控制器不接管任意外部数据库。

## 查询内容

页面顶部显示可用数据统计。导航提供四类目录：

- **物品与装备**：按名称、描述或 ID 搜索；可按类型、分类或装备部位、职业、性别、等级、价格、属性以及可交易、可购买、可丢弃、可堆叠等标记筛选。详情显示物品属性、装备属性和说明。
- **NPC**：查询 NPC 名称、描述或编号，可按地图、功能（商店、传送、关联任务）和可见状态筛选。详情可查看其地图坐标、商店或传送编号，以及关联任务和商店物品。
- **任务**：搜索任务名称、说明或编号，可按等级范围、发布 NPC、启用状态和是否可重复筛选。详情显示任务流程、前置任务、发布 NPC、固定奖励、经验或铜币说明及关联资料。
- **技能**：查询技能名称、说明或编号，可按职业、技能形态、学习等级、阶级以及服务端收录状态筛选。详情显示学习条件、冷却、吟唱、距离、前置技能及关联技能书或装备。

目录结果可以切换列表或卡片、排序、分页，并将筛选写入地址栏。最近复制和收藏的筛选保存在当前浏览器的本地存储中。NPC、任务、技能详情可以跳转到相关目录；符合条件的条目可复制 ID、传送或发奖命令，复制内容不会自动发送给游戏。

目录数据来自 PostgreSQL 中的物品、装备、地图 NPC、任务和技能表。页面调用 `/api/catalog/items`、`/api/catalog/entries`、`/api/catalog/relations` 和 `/api/catalog/meta` 读取数据；这些目录接口只接受 GET，不提供任意 SQL、业务配置编辑或数据删除功能。

## GM 工作台

“GM 手册”页提供命令目录、参数表单、命令预览和复制功能。命令预览会检查所需参数与部分服务端限制，但只会复制一条文本；GM 仍须以有相应权限的游戏账号登录客户端，并在游戏聊天中发送命令。网页本身不会代替服务端权限检查。

同页的“账号权限”面板可搜索最多 100 个账号及其角色，并把 `gm_level` 设为 `0` 至 `4`。保存会提交旧等级作为预期值，只有数据库中的当前等级仍匹配时才更新一行；冲突或账号不存在会要求刷新。保存后玩家须退出账号并重新登录，权限才会在新会话生效。

## 访问与权限边界

网页和 dispatch 没有账号登录页。物品、NPC、任务、技能目录 API 是只读接口，但 dispatch 默认监听所有网络接口，因此能连到该端口的客户端可以读取目录数据。需要将 dispatch 限制在可信网络；本机使用时绑定 `127.0.0.1`，不要把未受保护的目录服务直接暴露到公网。

账号查询与等级修改接口 `/api/gm/accounts` 额外要求请求来自回环地址，并校验本机 Host 与浏览器 Origin / Fetch 元数据；等级修改还要求来自网页面板的 JSON 请求标记，并使用旧等级作冲突检测。这是本机管理边界，不是登录认证，也不应被理解为可安全远程管理。GM 游戏命令则由游戏服务端按账号 `gm_level` 单独鉴权。
