# 330条独立效果用例的证据复核

本文件与最终门禁结果共同使用。机械门禁验证可追溯且实际通过的引用，不能代替对断言和合法fixture的语义检查。各领域逐条核对manifest；集成复核重点检查真实消费者、完整效果条款、独立单件与组合分类，并另做只读独立抽样。不声称额外审核人再次逐行重审全部330条、所有源码或穷举所有装备排列。

## 计数规则

- 分母只取当前catalog的330个唯一ID，通用80、五职业各50。每ID至少一个单威能主效果实际消费者，文案中的组合子句另列。
- “单威能”允许真实原生技能、普通装备和受控单位状态，不允许把另一个传奇威能产生的主效果当作该条solo。技能/状态消费者unit边界可用受控定义，但不能mock掉被测机制。
- 引用给完整Test/Subtest与实际文件/package；本次冻结生产代码的全server JSON及随后test-only概率边界补充运行验证pass、无skip，失败、中断、未运行不计。不同威能不能共用同一聚合solo，combo父节点不能包含已列solo叶。
- 只断言注册、文案、配置存在、未消费modifier字段不能计。覆盖率是用例/合同覆盖，不是Go语句、行或分支覆盖。
- 去重Test/Subtest引用与原始pass事件分别报告。嵌套父子引用不能再当成互不重叠独立场景相加。

## 发现并纠正的假绿与分类问题

1. JK-U01与ZS-U03/U04初版有移速临时字段断言，但没有足够实际消费者证据。补refreshStats、attributeSnapshot、playerMoveSpeedPX/权威移动及卸装恢复后才计入。
2. JK-U08旧聚合wrapper混入套装和多件构筑。改成纯单件生命周期/混合状态solo，原多件/套装矩阵只列组合。
3. 六处solo叶与组合父节点重叠，以及ZS-U06/YS-D01只有combo条款，均被机械门禁拒绝。展开准确叶名、分离单威能MP/盾主效果后重新验收。
4. TY-A11初版seed在有/无威能都暴击，不能区分+20个百分点效果。独立只读探针确认baseline与增强同为200；改用落在两概率区间的固定seed，同时断言无威能100、有威能200，并验证适用边界。最后追加baseCrit=0时精确随机阈值1999成功/2000失败、on/off及真实HP/暴击事件标记，避免误改成+100个百分点仍过。
5. TY-U11护盾/HoT排除项原来读实际ExpireAt再推进到该值，即使错误延长也会绿。改以固定10秒期望值及固定到期前/后时间作为oracle。
6. settled组合原把玩家防御威能装在攻击者，却让怪物受击。该布置不能证明玩家防御不重算。移除误导标注和无效装备；保留合法怪物native减伤与盾一次结算。当前PvP安全门禁使玩家TY防御受者不可达，不为测试绕开规则或扩大生产代码。
7. CK-A02的单件套装属性输入明确标为受控crit消费者边界，不冒称原生合法单件套装效果；普通单威能真实消费者与合法套装组合另有区分。

## 用例带出的实现边界

- TY-D10/D11/D19：纯承伤值修饰与生产性反击守卫分开，威能来源周期载荷也接受适用纯减伤/扣蓝；显式周期暴击减伤与普通入伤同加法桶。D11足/缺/零MP、盾、原生反射均核对次序，不递归生成新伤害。玩家承受威能DOT/显式周期暴击用例为受控消费者合同，不伪称现有PvP场景。
- YS-D05/D06相关硬控：真正成功且有效的硬控立即取消未释放windup；被保护压制的旧控制重新生效时同样取消；短控制消退不复活旧cast。免疫/抵抗失败、仍受压制的控制、原生瞬发无windup及已释放弹道都保留正确负例。只玩家有生产windup，怪物及无windup不进行无用列表扫描。
- TY-A04宽角：正式onUse到HP矩阵覆盖60/120/168/180/240/360度、四个朝向、固定半径内/边/外和数学半角边界。仅移除错误前半平面限制，并在点积比较加1e-9世界坐标单位容差；矩形/圆形不改。当前常见原生120→168不受原问题影响，宽角是明确支持的消费者边界。
- ZS-A08与同函数D02：依据既有domain百分比负属性floor规则，限制正常百分比Def最多减至-100%，保留原始低于-100特例，非百分比及其他属性不改。原生rank1/5/20、无威能对照、借用技能三件组合与原持续时长验证。真实combat.Strike表明Def0与负值同为100%命中/相同伤害，因此准确定位为状态/面板超原界，不描述为额外物理增伤漏洞。
- 来源分配：实际三陷阱接受source和ChildPreparation指针共用；后学/升级/换装不变旧源，新独立动作仍捕获新源。减少的是无条件捕获后立刻丢弃的冗余，不改变快照语义；不宣称所有child零分配或高怪密度压力已测。
- SS-U01：原生有/无威能均通过强制瞬移处理定身状态，不能把“原移动规则”误改成普通走路限制。只澄清玩家文本为保留原技能施法与落点规则，施法禁制/非法落点仍测。
