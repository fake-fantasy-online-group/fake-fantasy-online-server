# 万象秘典：道具与卷轴交互

暂定名称可由道具配置替换；客户端读取服务端 `powerBookName`，不将名称当作身份。

- 秘典道具 `1900028302`；威能卷轴 `1900028303`；任务 `1900030003`（万象留痕）。
- 首次成功分解暗金，保留原有最高数值收录逻辑，并在同一事务接取任务。失败、预览和回执重放不提前触发。
- 右下角原生提示引导前往龙城巧匠左慈（map 7 / NPC 73 / N611FY）。领取秘典与任务完成在同一事务，背包满保留任务。
- 旧角色已有收录时，首次载入档案补接任务；不清记录。不慎遗失可向左慈补领，背包、个人仓库已有道具时拒绝重复补领。
- 秘典右键打开全目录；范围、类型、部位三个筛选和“隐藏未获得”。未获得条目可悬停查阅但不能提取。
- 点击已获得条目提取绑定、不堆叠、不可交易的卷轴，不消耗秘典或记录，不新增费用。卷轴冻结提取时的数值；后续收录提升不修改已提取卷轴。
- 卷轴右键进入与外形相同的选目标操作，点背包或穿戴中的暗金装备完成附着。无新增确认链。服务端成功提交时才消耗卷轴并替换威能；保留装备其余数据。
- 新交互使用现有 endgame JSON 通道 `powerbook.extract` / `powerbook.apply` / `powerbook.recover`，不挪用变装 `0x1036` 的 kind。旧 `powerbook.imprint` 直写路径关闭。
- 目录仅反映服务端真实威能与部位资格，不恢复“职业威能只允许头衣武器”的旧限制。
- 新客户端声明 `endgame.power-codex.v1`；含卷轴实例的扩展快照需按能力协商，不能让旧 1.0.5 的严格 DTO 被额外字段破坏。
