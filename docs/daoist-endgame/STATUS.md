# 太清演劫录开发状态

本分支正在实现仙遗装备、二十八星篆与宿阵、演劫洞天、周天鼎四套玩法。

当前状态：开发中，不是可发布版本。此前沙箱成果未完成推送，正在从远端基线恢复实现。后续以本分支实际代码与可重复测试为准。

## 交付约束

- 小批次提交并核实远端保存，代码和验证状态分别记录。
- 不合并 main，不部署线上服务，不执行玩家数据库迁移。
- 不上传客户端美术、声音等外部资源。
- 不运行 Unity/Player 构建；源码与自动化验证不能替代实机游玩验收。

## 玩法验收目标

- 每个可染色装备基础身份有对应仙遗名称、属性和职业相关特性。
- 28 星篆、顺序及孔位相关宿阵、可执行战斗效果。
- 试炼钥匙奖励上限 14，洞天消耗、精英灵珠、进度、首领、结算与重连恢复。
- 周天鼎配方、消耗校验、预览、原子提交和重复请求保护。
