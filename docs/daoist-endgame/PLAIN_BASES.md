# 宿阵装备规则

宿阵要求「天生不带附加属性」的普通装备。判定读取服务端模板和装备实例，不能用名称颜色代替。孔位本身会增加显示属性数，因此已经开孔、镶入星篆后变色的普通装备仍能成阵。

## 权威字段来源

- `EquipDef.Bonus`：`internal/data/gamedb.go` 从 `gamedata.ov_arm` 的 `min_atk/max_atk/def/matk/mdef/hit_rate/max_weight` 读取。
- `EquipDef.Base`：同一主表的 `str/vit/int_/spi/agi/dex`。这两组是装备固有白字，与穿戴需求另列，也与额外词条子表分开。基础攻防、命中、负重和固有六维不会阻止成阵。原展示路径 `appendIntrinsicEquipmentStats` 同样将其作为白字，不添加附加词条的正号或百分号。
- `EquipDef.Affixes`：`loadAffixes` 从 `game_equip_extra` 读取的固定额外词条。任何条目都会阻止成阵，包括值为零的条目。
- `EquipDef.UnknownInnateProperties`：额外属性源行因概率语义未实现或名称未解码而被现有属性加载器跳过时，保留「无法确认是无附加属性装备」的状态。该标记不宣称实例实际获得了未知属性，不改变实际属性、随机词条池或孔位预算。此类装备保守拒绝，提示「这件装备的天生属性尚未确认，不能组成宿阵」。
- `Stack.RolledAffixCount/RolledAffixes`：掉落生成时抽定并保存的随机额外词条。非零条数会阻止成阵；条数为零但数组残留非零词条的异常数据同样拒绝，不将其默认为白板。
- `Endgame.UniqueID`：仙遗标识。仙遗自身有额外属性及特性，不能组成宿阵。
- `EquipDef.Suit`：`internal/data/equipment_suits.go` 从 `ov_excesuit` 读取的套装成员和条件效果。存在套装 ID、成员分组或奖励即不属于普通装备；无需等套装效果实际激活。空的占位结构不会单独造成拒绝。

`RefineLevel`、`WashAffixes`、换形、装备灵、龙、已开孔和孔内卡是后续养成状态，不计入上述天生附加属性判定。原有五条属性容量规则不变。

源数据审计：`000000_init-32.sql:33428/33431` 的两条 `prob=30` 记录分别为 9361 珍稀火蝶面具的爆击率、9362 珍稀蓝蝶面具的魔法爆击率。这两件同时已有两条确定固定词条（力量或智慧 9、最大负重 200），所以其不合格结论不依赖概率究竟表示何种触发/生成语义。另有 352 条未命名记录涉及 68 个模板，其中 19 个没有其他已载入固定词条。未解析数据只记录为未知，不能依据这些行断言实际属性已经生成。

## 统一判定及已有物品

`AstralBaseEligible` 是装备规则入口，`AstralBaseIneligibility` 统一提供不合格或资料未解析原因；`MatchAstralRecipe` 必须先通过它，再检查真实孔数、顺序、部位、卡 UID 和快照。因此装备视图、成阵等级、穿戴后属性、战斗和重新登录重算均由同一条规则派生，不保存另一个可能过期的成阵开关。

周天鼎的布宿成阵和移星换斗在预览、提交两条路径都显式拒绝不合格装备。失败计划不会发布候选背包或扣除真实材料、铜币。

规则不删除或改造已有装备，不重写装备 UID、孔数、顺序及星篆 UID/效果快照。不合格装备失去的是宿阵匹配和宿阵额外收益。原装备、独立星篆和其他合法养成效果继续按原有等级、职业、耐久与属性规则计算。

单枚星篆仍可镶入有合法空孔的带属性装备，作为独立星篆生效；它不会因此绕过装备规则形成宿阵。提取单枚星篆和周天鼎原样取回孔内卡继续可用，仍受原有锁定、孔位完整性、背包容量和费用限制。只剩独立星篆时，装备需求等级保留原装备及星篆的要求，不额外套用一个实际未成阵的宿阵等级。

这次修改无需数据库迁移或实例重写。已有持久化字段足以在重新读取模板、实例后重新判定。

## 验证范围

`internal/domain/endgame_runes_base_test.go` 覆盖白字基础属性、后续养成与颜色无关、固定/随机/仙遗/套装排除、异常随机词条、完整实例序列化往返后判定、独立星篆效果、原样提取，以及周天鼎预览/提交失败的输入隔离。完整服务端检查以实际执行日志为准，序列化单元测试不代表生产数据库或实机客户端验收。

`internal/data/equipment_affix_provenance_test.go` 直接验证加载决策：已解析词条正常载入；概率未实现或未命名源行只标记未知，不赠送属性、不占用额外孔位预算。该单元测试不能替代真实 PostgreSQL 查询验收。
