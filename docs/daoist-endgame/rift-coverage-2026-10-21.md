# 洞天可玩区域密度与守关轮换（规则 v8 / 生成器 v4）

## 行为与兼容

迁移 90 复制已发布 v7 为 v8，只增加 `floor_layout_version=4`、`guardian_recent_window=3`。新局生效；旧规则字段为 0，已保存楼层及旧局后续楼层保持 v1–v3 算法。新服务端读取尚无新增列的数据库时按 0 处理；启用 v8 前必须准备兼容服务端。原生技能、等级/难度缩放、时间、每怪/球进度、结算奖励与钥匙消耗不变。

- 根据真实 MASK 四邻连通区构建有界 BFS 区域，最大面积 320×100352 px²；丢弃不足最大区域一半的切分碎片，避免巨图抽中小边角。
- 全区域 64px 对齐安全格点取代原生怪锚点 160px 限制。完整 64×64 格必须可走；窄通道只连接区域，不用于塞怪。不使用旧目录的 32px 补点。
- 数量为安全格面积 / 100352，最少24、最多320，候选不足时不硬塞。最远优先布遭遇中心，中心尽量带3–5只近邻，组成4–6只小组。入口160px、出口80px留空，出生点间距至少64px。
- 蓝精英约7.5%、黄精英约2.5%，不超过既有24蓝/8黄、320总实体及既有分身/快照预算。
- 入口、种子出口与刷怪处在同一可达区域。没有隐形墙、封路、地图裁剪或禁止探索。超大图其他边缘仍可能为空，不是全图均匀或动态分批刷怪。
- 10000总进度、普通怪40、每球200和原球数不变。小图24只通常需要通过已有出口/原生门换层继续累计，不能再承诺每图一层出Boss。没有暗改进度和奖励，但实际完成时间/每小时收益仍需实机校准。
- 已有8种原生Boss及各自既有3词缀组合保留。开启者个人最近3次成功付费开局的Boss加入有界历史，新局排除后按种子抽取。历史、扣钥匙、建局一次原子提交；失败不改历史。Boss存入局快照，换层/重连不重抽；不做全服共享。不把现有8种称为新增内容。
