# 太清演劫录

在现有客户端与服务端上新增四套相互连接的玩法：仙遗、星篆与宿阵、演劫洞天、周天鼎。

## 进入玩法

使用客户端与服务端各自的 `feature/daoist-endgame` 版本。协议在登录进入世界后协商 `endgame.v1`；未协商时客户端不会开放演劫操作。

进入游戏后按 **F8** 或点击右侧 **演劫 · F8** 按钮，打开四页玩法面板。

1. 原有试炼任务完成后，回四村的 **试炼小仙** 处领取奖励，其中新增绑定的洞天符钥。
2. 与原有 **妖魔结界守卫** 交谈，然后在面板开启演劫洞天。队长消耗一枚符钥，可带最多四位同队道友；从第一层开始逐步解锁。
3. 击杀普通怪物、精英光圈怪并靠近镇煞灵珠，填满进度后迎战镇境劫影。击败首领后在面板领取固定下来的奖励；背包满时奖励保留，重试不会重掷。
4. 在星篆页选择装备、孔位和背包星篆，按顺序组合宿阵。战阵、守阵、辅阵各取最强符合条件的一组。
5. 在周天鼎页选择配方与物品，先预览再确认。预览不扣物、不掷随机数，60秒过期或物品变化后需要重新预览。

仙遗名称与特性可在面板查看。装备14–25号槽位保留原编号，在扩展装备清单中操作。新的装备和符文继续使用本地既有素材，仓库中没有新增外部美术资源。

## 已有数据库升级

本项目的 `cmd/migrate` **只用于空库初始化**。已有数据库不能再次执行全部初始化分片。

升级前备份并停止会写入玩家存档的旧服务。核对目标数据库后，用 PostgreSQL 客户端执行新增的、只扩展结构的迁移：

```
psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f docs/migrations/20261011_daoist_endgame_v1.sql
```

迁移扩展玩家试炼字段、装备实例覆盖信息和演劫状态/回执/副本表，不生成玩家奖励、不重写既有物品。仍须自行核对目标数据库、备份与升级环境；本次开发没有执行任何线上迁移。

新数据库按仓库原有说明运行 `cmd/migrate`，现在包含 `000000_init-50.sql`。

## 构建与验证

服务端仍使用仓库根目录 `make build`。客户端继续使用原有 Unity 项目、已安装的资源目录和现有登录配置。不要重新生成与现有客户端不匹配的握手密钥。

源码、测试与发布状态分开记录，见 [VALIDATION.md](VALIDATION.md)。本次没有运行 Unity Editor、PlayMode 或 Player 构建，也没有完成渲染后的游玩验收。自动化通过不等于已部署或已实机验证。
