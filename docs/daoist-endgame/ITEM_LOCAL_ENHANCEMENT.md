# 本件强化与少量浮动属性（v4）

## 执行口径

- 新的 LocalEnhancements 只允许攻击47、魔法攻击15、防御13、魔法防御17。每项以本件 EquipDef 原始白字为基数，先以 int64 计算 `基础值 × 百分比 / 100`、向零取整，再作为绝对增量进入装备结算。攻击47分别折算最小/最大攻击，不能进入共享的角色攻击百分比桶。
- 加工增量与本件强化各自取原模板基数，不彼此相乘。角色六维、其他装备、附加黄词条、卡片快照、洗炼和融合不作为本件强化基数。后续原有角色百分比仍按既有战斗顺序作用于装备后的角色面板。
- 既有 Attr/Mode 含义不变；旧 Mode1 仍是原来的全局百分比，不重解释旧装备/星篆快照。没有创造所谓原版强化新Attr，原版确切“强化”标签尚未由源数据证实。
- 宿阵仅在既有职业、等级、部位、耐久及通道优胜规则通过后，依据获胜的确切装备UID折算局部属性。零基底的强化折算为零且不显示生效强化行；其原本至少五项额外属性仍独立有效。

## 固定与浮动

- Affixes 是固定主体。只有 VariableAffixes 中指名的现存Attr会改变；Traits、诅咒和未标记行不再跟随灵性整体缩放。
- 每件至多两项浮动属性，含局部强化浮动；至多两项局部强化。新目录保留原有至少五条有益额外属性，不用基底、卡片、特性、局部强化或未实装技能等级凑数。
- 原 UniqueRollBP 的8000–12000原值不改。只把它映射到11个质量档：`(roll-8000)*11/4001`。同件明确浮动属性共享该档，便于毕业；最高档含363个原始取值，概率363/4001（约9.07%），而非只有12000这一个完美点。
- VariableAffixes Min/Max 是数值边界，攻击速度负值按收益方向反转。局部MinPercent/MaxPercent省略时固定；目录保留完整边界，普通tooltip只显示本件当前数值。
- 新装备创建时独立产生一次 FormationRollBP 并随原UID持久化。既有零值永远按10000中档解释，读取、重连、插拔、换配方均不补掷。未改变装备身份、旧黄词条、UniqueRollBP、孔位、卡UID/快照、加工、洗炼或融合。
- 返本重铸只从可见浮动值不同的结果中抽取；完全固定的定义不能消费。炼真守一必须带来可见提升，所有变量已满值时即使旧原始值不足12000也不能消费。

## 显示与兼容

- endgame.v1 JSON的字段集合不变。新客户端请求并确认 `endgame.native-stats.v1` 后，服务端原生物品描述负责权威合并；旧客户端保留原显示路径。
- 合并只发生在仙遗/已成宿阵的额外区，按Attr+Mode+作用域匹配；符文与宿阵的相同普通词条合计，本件强化百分比始终独立，不能和角色百分比混合。
- 本件局部绝对增量进入白字攻防，只显示一条“攻击强化 +X%（本件）”等说明，不再把同一折算量另列为额外加成。基础白字用原生质量0前缀，孔数用原生暗金前缀。
- 已匹配但损坏、受压制或不满足使用要求的装备，显示潜在数值并沿用“不生效”提示；实际战斗结算依然按激活规则严格过滤。普通/未成阵及独立星篆展示不被改色或合并。
- Session只按endgame.v1开放侧路传输，必须将hello及原始capabilities转交Scene，不自行提前确认。Scene在hello成功前先刷新原生背包/穿戴描述，再回传能力确认，最后发演劫快照；实际wire层沿用库存差分，重复hello若描述不变可不重发库存包。描述构建失败不确认能力，返回可重试busy。能力保存在在线会话运行态，跨图携带，重新登录须重新协商；查看别人装备按查看者的能力选择格式。

## 数据库升级与回退

新空库包括000000_init-51.sql。旧库先停服、备份，再执行 `docs/migrations/20261011_item_local_enhancement_v4.sql`；脚本有事务且可重复执行，只增加带0默认值的formation_roll_bp和独立约束。不要对非空数据库重新运行完整初始化。

回退二进制时保留新增列及其值：旧版明确列名的四列INSERT/UPDATE不会抹掉已存新roll，新增旧版装备得到默认0。重新升级能恢复原值。删除列会不可恢复地丢失新roll，不作为安全回退步骤。任何实时库应用或回退须单独按部署流程进行；本次代码工作不执行用户环境数据库迁移。
