# Rift v9 / generator v5 density

New admissions use `min(320, ceil(v4 population * 1.5))` total ordinary/elite monsters. The explicit cap is intentional: dense maps do not promise a full 1.5x increase. For example 24→36, 203→305, 241→320. Blue and gold counts retain their v4 absolute values; only ordinary monsters are added. The single guardian, monster stats, per-kill progress, drop rules and guardian rewards are unchanged. More ordinary monsters can alter completion pace and total loot opportunities; this is not an economic-neutrality claim.

Geometry, native MASK regions, 64px spacing, existing encounter coordinates and entrance/exit selection remain v4-compatible. No waves, additional walls, fallback overlaps, protocol limits, aura omission or client changes. Existing v8 runs retain v4 frozen rules and saved floors. Migration 92 copies v8 to v9, changes only the rule version and layout version, verifies class/ability equality, and advances only the active v8 selector. Deploy matching server code before activating v9.

Regression coverage:
- Domain: exact capped formula, old point-prefix preservation, entry/exit equality, unchanged elite counts, v4/v5 JSON persistence and version gating.
- Full native catalog: `FFO_RIFT_COVERAGE_AUDIT_TEMPLATES=<templates.json> go test ./internal/data -run '^TestRiftDenseNativeCatalog$' -count=1 -v`. Generate input with `tests/rift_layout_audit.py --templates-output <templates.json>`.
- The catalog scans every retained region/candidate and 20 independent seeds per map, compares v4/v5 counts and entry/exit, reconstructs native MASK paths, and validates compressed path segments at one-pixel resolution. Local crowding is reported as neighbors within 192px. It does not execute Unity or prove temporary combat obstacles absent.

Migration SQL has static review only in the cloud coding environment; actual PostgreSQL execution belongs to deployment validation.

Validated 189 maps, 214 retained regions, 1,075,859 candidate coordinates and 3,780 plans (20 independent seeds per map): no count/geometry/path failures. Sampled population range is 24–303 → 36–320; mean 199.65 → 264.28 (+32.37% under the explicit cap), with 1,865 plans at 320. Each map's representative 192px-radius local crowding peak remained at most 6. All rift-focused domain/data/scene/protocol tests passed. This finite seed sample does not claim exhaustive RNG-state coverage.
