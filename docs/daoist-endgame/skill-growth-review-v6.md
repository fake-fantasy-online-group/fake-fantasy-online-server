# 全149技能高等级边界与后续改法：最终代码审计

> 历史审计：以下保留此前v6数据与当时缺口，不代表当前规则。现行实现与系数见[149技能新成长实施政策](skill-growth-implementation-v7-zh.md)。

审计日期：2026-10-12。基线提交 `cf675ad`，包含本轮工作树“直接整数 mpCost”修订。这里的等级 r 是有效技能等级，不是角色等级；硬投入仍最多20，装备等软等级另加。本表以原1–5技能行加 native restoration 恢复层为起点，不能把未恢复的机制算作完成。

## 先说结论

- 全部149个职业技能均已逐项纳入：37被动、112主动，其中56功能/治疗主动使用直接减耗。
- 概率、减伤、反伤、百分比惩罚、持续时间、HP/MP、整数时间与目标集合各有真实边界。触到某条边界不等于整个技能完全没收益；其他轴继续长也不等于原缺失机制已补齐。
- 本轮已落实：直接降低现有 `mpCost`，显示/准入/扣费一致；删除“法力效率”、分数余额、零头返还。不是每升一级必少1点，正消耗最终会到1点。
- 全149技能在20→21、21→22、30→31、50→51、100→101的745次定义/载荷比较，当前混合审计记录31次平台。冷却以真实100ms逻辑帧比较；被动减耗以原受益主动5级、无额外装备的实际整数费用比较。其余有载荷变化也不等于在所有实战情境都必有收益；鹰眼未接通路径另做真实施加测试，不能合成一个“全运行时通过率”。
- 新查出的隐身移速翻正、鹰眼成长未接运行路径、枷锁实际早停、抗魔不覆盖新移动定身ID等，下文均单列；本次没有擅自修这些业务。

## 统一公式及边界

1. 原普通斜率 L：r>5 时，数值从五级值 B 延续为 B+(B−A)×(r−5)/4；整数轴按代码向零取整，并执行该轴真实上下界。概率不超过100%，百分比惩罚不低于−100%。原1–5行逐行原样保留。
2. 原恒定直伤/治疗倍率 M：只在本来就有的非零伤害/治疗通道使用 B×[1+(r−5)/50]，允许有理数伤害/治疗计算。整数状态数值采用 B±max(r−5, floor(abs(B)×(r−5)/50))；因此燃烧20点变为20+(r−5)。这不是给任何技能凭空加伤害。
3. 功能主动 U：r>5 时，E=r−5；实际蓝耗=ceil(50×C/(50+E))。C是装备/训练修正后的基础整数消耗，裸技能为原五级C5。已有吟唱/冷却毫秒数 T 变 floor(50×T5/(r+45))。没有原时间就不新增时间。正C降到1的首级为50×C−45，T变0的首级为50×T−44。其他修正存在时，首级必须按最终C/T重新计算。
4. 原被动定向减耗：E按下表给定，叠加到原目标的减耗参数后再一次整数结算。若固定目标基础费用C，E≥50(C−1)后永远1点；无法宣称无限减耗。被动等级增长并不保证目标伤害技能自身同时升高时蓝耗还下降，因为其原蓝耗也可能上涨。
5. 控制压力 P：只在允许增长的控制持续时间达到边界后，把后续等级转为压力。实际数值抵抗=floor(min(max(原抗性,0),90)×100/(100+5P))；P=1781首次使所有0–90整数抵抗结果全0。之前也有离散平台。真正免疫/阻挡有害状态独立，不穿透。
6. 冷却：实际帧数=ceil(毫秒/100)。毫秒少1不一定能更早施法；吟唱使用毫秒墙钟截止，但场景处理时序仍可能合并感知差异。56功能主动的1点MP、1帧冷却区间与0毫秒边界全部列在后表。
7. 目标/范围：本轮成长不增加原单体/范围形状、距离、范围尺寸、效果段数、状态数量或被动目标列表。原范围技能命中多少单位取决于场景中合法目标，不存在按等级不断扩人数的分支。装备变体/硬点训练是另一路，不算这里的技能原等级改法。
8. 引擎不是数学无限：有效等级转换要求≤2147483647，原效果外推超出int32时会拒绝，不能把字段计数能增当作无限可用收益。

## 逐项高等级边界与固定机制

U、M、L、P的精确定义见上。表中“首次”指升到该级已经触到边界；不是下一次无变化的等级。固定机制明确标为固定，不能冒充高等级触顶。

### 本轮实际代码核验发现

1. 隐身术10208移速翻正：原五级额外移速惩罚为0，但 `skill_curves_v5.go::affixValue` 的移动分支把−25→0继续线性外推，6级+6%、21级+100%。主状态零词条保持0，额外词条却翻正，和“零值不生成新正收益”的旧声明冲突。没有在本轮改它。
2. 神术：鹰眼10327成长路径没接通：领域resolver在11级为60秒，100级P=89；但 `visibility.go::revealInvisible` 使用原 `statuses.Get`。独立实际路径测试 TestSkillGrowthAuditEagleActualPathGap 在5/11/100/1792级均确认实际施加30秒、P=0。当前U减耗有效，但宣称60秒及压力成长的那部分未实现。
3. 枷锁术10325实际早停：字段15级到100%攻频损失，但 `PlayerAttackSpeedPercent` / `ApplyMonsterStatusStats` 最低攻频50%；不考虑目标其他加速时，5级的50%损失已到实效下限。6–15级只是字段继续长；有其他加速时可能抵消得更多，不能给所有目标一个统一实效触顶等级。
4. 抗魔10026的原名单是冻结1004、石化1005、时封1034、缴械1006。恢复后的金缚剑10111及狙击10221用移动定身状态ID10111，所以当前既不吃该被动的精确状态抗性，也不触发其抵抗回蓝。是否扩入名单是设计决定，当前不能说它覆盖所有“定身”。
5. 抗吟唱打断也有实际地板：仓库种子基础打断40%、最低5%，10314在15级已到5%地板，字段到17级才100%相对减幅；10416在原5级到地板。实时数据库如改了配置，实际首级应重算。不是“100%减幅等于不会被打断”。
6. 抵抗被动原字段100%不等于真实免疫：10008/10025/10026/10108在裸抗性9级已到实际90%，10级字段100%但回蓝仍0，11级才开始1点回蓝。装备抗性会让实际概率更早到90%。

### HP/MP和同类整数边界

- 治愈术10301、群疗术10304到19/20级时原最大HP治疗比例100%；无治疗惩罚/变体时，普通直接治疗已能补满，额外固定治疗继续增并不增加本次实回。带固定治疗部分时，依目标MaxHP、当前HP还可能更早补满。
- 复法术10302、饮血剑10104、噬魂剑10119、破法之枪10013、回春术10303、毒雾10214和其他直接伤害/周期伤害均受当前缺失资源/剩余生命约束，统一的技能等级无法确定“本次满回/一击杀”的首级。不是因此把原伤害成长删除。
- 10322/10418的延时倍率继续长，但被加长控制仍需通过接收技能的持续上界；对已到上界的同一控制没有时长收益。
- 陷阱回避/魔法回避的新同类减伤最终对固定伤害D会到1点，不会产生0伤免疫；回蓝触发在满MP时没有实回，反击、击退、附毒等仍有各自原触发条件。
