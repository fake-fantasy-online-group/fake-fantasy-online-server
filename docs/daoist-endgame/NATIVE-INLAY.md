# 星篆接入原镶嵌炉

操作使用现有镶嵌炉：先将装备拖进装备槽，再将背包星篆拖到已开启的空孔。原生打孔、镶嵌、背包和孔位返回包的编号、字段与帧格式均不变，不新增专用星篆工作台。

## 规则

- 星篆镶嵌消耗所选的一枚星篆，无额外铜币或材料，无随机失败。原有非星篆卡片仍使用既有配方、成功率、材料、费用和损毁规则。
- 保留星篆 UID、保存的属性和绑定状态；绑定星篆会使目标装备绑定。
- 每次只镶一枚星篆，已有星篆在装备满足使用等级时各自提供属性，不要求凑齐一整套。
- 填入最后一个空孔后，只有底材无天生附加词条、实际孔数、从左到右的星篆排列及配方部位相符，才追加宿阵；未成阵仍保留每枚星篆属性。现有职业与等级条件继续控制宿阵生效。
- 使用等级取底材使用要求与全部已镶星篆要求的最大值。当前宿阵配方没有独立的底材等级门槛，不新增未配置的限制。
- 检查角色等级、装备/星篆锁定、孔数上限、空孔、实例归属与重复 UID。满背包不妨碍镶嵌，因为只消耗星篆。
- 删除新增的独立“星篆镶嵌/取出”入口与按钮。旧 `socket.remove` 请求不再执行新操作；既有分离卷轴和周天鼎已有提取规则不变。

## 一致性

装备查询记录所选装备状态、背包星篆实例与存档版本。延迟的槽位请求不能作用于替换装备或替换卡片；回执查询之后、提交之前再次检查。存档未读取完成、交易或其他经济操作占用时不执行。

星篆使用现有原子结算后端，一次保存背包、装备、版本和稳定回执。保存成功前不发布候选状态；失败保留原物品，原请求重试沿用同一回执编号。重复包不能重复消耗。成功后返回原生提示与孔位数据，并更新同一炉内的选择，支持连续镶嵌下一孔。
