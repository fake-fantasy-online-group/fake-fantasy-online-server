# 仙遗名称长度审读：保留好名，放开字数

日期：2026-10-11。范围：`catalog/authored/*.json` 中全部 1,619 条仙遗记录的 `Name`。本轮接续 `name_audit.md` 的去硬凑数字审读，以本轮开始时的真实名称为比较基线；不覆盖上一轮的历史改名记录。

## 结果

- 逐件显式改名 364 项（22.48%），保留其余 1255 项。没有先设长度配额，再为达标改名。
- 四字名由 1067 项（65.90%）降至 704 项（43.48%），仍是最大的自然长度组。
- 两字名 82 → 199，三字名 300 → 453，五字及以上 170 → 263。
- 全部 1,619 个名称互不重复；没有空名，没有新增阿拉伯数字、编号或机械递增后缀。
- 每个入选改名都回看该件 Lore，再确定物象、动作、来历或悬念。第二轮复核撤回了仅仅拉长句子、缩得生硬或不如原名的候选。既不将同一套前后缀批量附着，也不把几个相似词根循环排列。
- 这里只调整 Name。写入逐文件读取最新 JSON，仅替换对应 BaseID 下的 Name 文本，逐件比较所有非 Name 字段，写入前检查源文件未被并发改变，再原子替换；写后重新核验所有非 Name 字段完全一致。
- 本轮写入核验保留 Lore、LoreRoot、Identity、Benefit、Tradeoff、PowerTier、Affixes、Traits、ReservedSkills 和所有 ID，不改任何属性或物品身份。后续独立的属性工作可以合法修改自己的字段，不属于本命名轮次。
- 宿阵及星篆不在本轮范围。未运行目录生成器；生成目录由总集成步骤统一更新。

## 保留尺度

- 两字名取能独立立住的核心物象，如“借火”“茶脉”“缝夜”“泪筹”，并非把所有四字名机械砍半。
- 三字名允许具体器形或关系，如“长夜瞳”“针孔春”“不熔铜”等各依故事选择，不强制某一种句法。
- 长名用于确实需要展开的独立来历或话语，如“输棋空处有雷声”“未下水的渔袖”“任期长过仙宫”。不为增长添入空泛的“之”“的”或相同收尾。
- 仍保留“不拜三清”“未分两仪”“两仪歧路”“四时药印”“六壬门环”“九宫在掌”等有具体文化语义的名称；不把自然出现的概念和数词一概删除。
- 例如“偏翼画圆”“金漆未干”“焦痕续雷”“识尽仍疑”“倒植金莲”保留四字原名，理由是原名已经简洁有力；长度从不是压倒质量的目标。
