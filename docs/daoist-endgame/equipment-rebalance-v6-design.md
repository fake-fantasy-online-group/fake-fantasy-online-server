# V6 暗金与宿阵：构筑强度和差异化设计

日期：2026-10-12。依据：本轮用户已授权重设和实现；此前 `EQUIPMENT_SKILL_VARIANTS_PROPOSAL.md` 的 DRAFT 不再代表本轮未授权。本文是研究与实施验收规格，数值区间均为调参起点，不冒充运行测得结果。

## 1. 立即采用的结论

- 保留 259 暗金、40 宿阵、28 星篆的身份和范围。暗金沿用过渡183／小高货54／质变18／神装4；强度不能继续全挤在黄装的1.1–1.5倍面板。
- 每件暗金至少5条真正有用的附加属性。强黄对照使用真实自然词条及孔位配额，不拿白装或虚构弱黄充数。普通属性好装与纯增强好装都保留。
- “数倍”是少数神装对适配构筑的实际收益：单件替换目标3–5倍；不是每件、每职业、每场景全部3倍，更不是把4目标总伤冒充单体4倍。
- 不新增召唤物；原技能身份和基底不改；新施法随卸装恢复。一个技能一个主形态，仅组合明确兼容支撑。
- 光环全部属于宿阵。暗金1107伏虎磐、1111炉门客卿、2603羽端白尘的旧光环需移出，补回个体构筑价值。装备卡只列光环名和等级，具体作用在人物无倒计时buff说明；服务端租期照常用于及时回收，不能因为隐藏时间而永久驻留。
- 名称继续来自器物经历、人物关系、民俗和道教观念。保留“泉下欠条”“鳞下不留名”等独立叙事，不按“火系神杖/极品玄天”模板批量改名。

## 3. 实际仓库现状与不能误读的公式

核查时目录统计：259件中221件带生命；元素伤害只有7条、穿抗1条、攻速属性7件、触发3条、光环3条。物理武器多为物攻／力量／命中／会心／生命重复排列。四神装分别为1310无名神席、1510问渊、1610泉下欠条、1810鳞下不留名。

代码依据：`server/internal/domain/stats.go`、`unique_effects.go`、`elemental_combat_v5.go`、`endgame_item_local.go`、`equipment_effects_v5.go`，以及 `server/internal/game/combat/damage.go`、`strike.go`。

- 物理基础：均匀取攻击上下限，再乘技能倍率，扣固定物理抗性。物防参与回避，不是物理减伤百分比。会心固定2倍，并在物理命中判定前发生；会心同时改善必中概率，不能简单套一个外部DPS模型。
- 法术正式路径：魔攻×技能倍率－0.63×魔防－固定魔抗；最少1点。旧比例魔防函数已标记弃用，测评不得引用它。
- 元素增伤与普通暗金伤害trait进入同一个增伤桶，现封顶+100%。同名trait只取最强，不按件相乘。
- 元素抗性实际值：先原始抗性减穿抗，再限制在-50%至75%；穿抗PvE最多30个百分点，PvP最多15。原始抗性超过75%的部分能抵销穿抗。若抗性75%降为45%，伤害保留从25%到55%，局部收益2.2倍；抗性0%降为-30%则仅1.3倍。此算例是本项目公式，不是D2规则，也不是整件装备测试结果。
- 减伤桶现封顶45%、耗蓝/施法缩减各50%；这些值如不另改，目录再填高只会浪费。穿抗不能穿越硬免疫。
- 武器局部强化仅作用本件未加工原生白字，不放大卡、加工、别件、六维、额外平加。最多2条变量、11档共享roll，历史UID和roll不得重掷。
- 攻速额外词条用现有 `AttrAtkSpeed` 的合法负值百分比；物理与法术会心用bp，不能写成百分比模式。法系节奏走真正的施法时间、冷却和动作限制，不假借物理攻速。
- 现有固定等级触发只支持白名单单目标伤害/治疗，ICD最少4秒，还有根事件和全局约束。不能把增加触发概率宣传为等比例DPS，也不能默认继承软点、训练和装备变体。
- 现有光环只支持物理减伤、元素抗性。若要冥思式回蓝或信念式减抗，必须实现运行通道、限额和测试后才能投放；不得只写描述。

`endgame_card_budget_integration_test.go` 的physical评分仅平均物攻，magic仅魔攻，sustain仅MP；防护评分也为单固定样本。`unique_v5_budget_test.go` 的神装作者目标约1.28–1.48，是底盘验证，不是实际数倍战斗证明。保留这些作为基础检查，新增运行验收，不能把静态门槛改大就宣告完成。

## 4. 属性家族分布：可落实的目录规则

每件先给一个主身份、一个次要价值；至少5条有效附加属性。不是为了凑5条把职业无效的力量/魔攻放进去。下列比例是目录设计目标，重叠统计，不是按ID取模自动轮换。

### 暗金

- 物理武器按身份分为重击底盘、迅击会心、单技能精研、精英/条件猎杀、续战回收五家族。任何一组相邻5件至少覆盖3家族；同样5属性签名不应占本职业武器半数以上。
- 施法武器按单系增伤穿抗、单技/学派软等级、施法节奏、法力循环、救治五家族；火/冰/圣/暗仅给实际有合法伤害来源的构筑，普通魔法伤害不能冒领元素词条。
- 高价值以上物品至少有2个实际可生效的环节，例如白字+攻速、软点+穿抗、治疗+耗蓝、会心+精英专精。可以没有复杂特效。
- 全目录起始覆盖目标：攻速20–35件；法术节奏/耗蓝20–35件；元素伤害20–35件；单系穿抗12–20件；技能软点35–55件；条件专精25–45件；固定触发8–14件；主变体首批5件；光环严格0。类别可重叠，不同时塞入每件。
- 非武器也承载专精，但首饰/头部以技能、元素、回收为主；衣盾以真实抗性/减伤、急救和续航为主；鞋以走位/节奏为主。生命仍有价值，不必为了统计机械删除。

### 宿阵

40阵建议主身份配额：8个攻击专精、6个施法/资源、8个护体/抗性、6个组队光环、6个技能精研、6个移动/刷宝/续战。每阵只有一个主身份，可带支撑。既有材料顺序、通道胜出、孔位/card快照规则不变。

优先使用已支持的6个防护光环，按不同元素/物理压力定位而非6种文案同效果；不要求40阵全带光环。“光环全在符文之语”不是“每个符文之语必须有光环”。神级宿阵也可纯属性或技能支撑，不与暗金一起堆全能。

## 5. 四档强度与roll验收

| 档位 | 全部低roll必须满足 | 适配运行指标（设计目标） |
|---|---|---|
| 过渡183 | 同级强黄主价值至少1.10倍，≥5有效条 | 对应输出/续航/生存1.15–1.45倍；允许简单可靠。 |
| 小高货54 | 主价值至少1.20倍，存在第二有效价值 | 对应指标1.4–1.9倍，非适配技能不强求。 |
| 质变18 | 普通底盘不弱于强黄，机制实际可执行 | 对应玩法指标1.8–2.8倍，或带来原来不存在的站位/时机选择；不能以群伤替代单体合格。 |
| 神装4 | 底盘不倒退，所有广告能力实际有效 | 低roll单件替换在声明的主要构筑至少3倍，中roll目标3–5倍；高roll检查组合爆炸。 |

倍率是建议验收目标，不是给每类属性单独设置同倍率。无输出职责的护体装用存活/有效治疗指标，不强迫DPS3倍。纯增强不强制负面，代价可以来自槽位竞争和适用范围，不伪造负词条。

## 6. 四神装调参起点与五个基准构筑

所有数值要由最终测试回调；目前没有宣称已测得以下收益。

1. **问渊1510：剑客重剑单体。** 54级同硬点，真实普攻为主、另跑单体剑技。原生白字20–164。起点：局部物攻+350–500%、攻速+35–50%、会心+8–15个百分点，配命中和物攻上下限；纯数值神装不用强加群攻。目标60秒单目标有效伤害≥3倍；双手不能同时把盾牌收益计入。群怪收益和实际受伤另报。
2. **无名神席1310：术士单系法术。** 54级、10401火弹或10409冰箭选择一个主测构筑，原生魔攻64。起点：局部魔攻+300–420%、全技能+2或指定单技+4、瞬念25–40%、选定元素穿抗15–25个百分点。目标单体60秒3–4倍；另测低抗0%、高抗60%、原始超上限90%，不能只挑高抗且基线打1点的目标。法力用同起始资源和药水预算，空蓝停手算入。
3. **泉下欠条1610：战士低血决战。** 局部物攻+220–320%、低血≤30%伤害+60–90%、职业软点+2作起点。声明低血适配窗口3–4.5倍，满血另列，不能固定无敌低血来证明整场收益。脚本包含受击、移动与死亡；报告低血覆盖时间、60秒总伤及存活，不把死亡后的理论攻击补上。
4. **鳞下不留名1810：刺客猎首。** 单技10219伤害部分，免控精英作为主要目标。原生白字20–66，局部+250–350%、精英专精+70–100%、单技+4–6、会心+10–15个百分点作起点。目标精英单体3–5倍；普通目标另报。控制抵抗/免疫不能被伤害倍率顺带绕过，不能把击晕延长算成首领无条件收益。
5. **药师护生／宿阵续航：支援独立基准。** 固定队员人数、站位和伤害输入脚本，单体急救、三人持续压力分别测试有效治疗/MP和存活。首批药师变体优先同目标有限二段护生或有限充能节奏，避免把基础治愈术直接变为廉价群疗、吞掉原群疗技能定位。不得把满血过量治疗算收益；若采用三人小圆，必须证明距离、目标数、总治疗预算和MP上不会全面替代独立群疗。

前三种形态不能都成为免费清屏：剑客短扇形、战士窄直线是不同几何但仍需限目标/边界；刺客引线强调已布置陷阱的时间选择；药师护生强调救急时机；术士快发强调走位与实际循环。技能名/ID和学习条件不变。

## 7. 倍数验收的硬合同

### 对照构造

- 同角色等级、六维分配、所有硬点与训练协同、其它装备、加工、目标抗性和AI脚本；仅替换声明的一件暗金或宿阵。
- 强黄来自对应等级/底材/职业的真实roll池，满足最多5自然词条与孔位预算。选择对该构筑真正有利的最高合法组合。固定词条占自然配额，孔位也占配额，不能同时构造五顶级词条再免费满孔卡。
- 附加“相同总孔卡/加工投资”的可行对照；使用真实Compute和卡快照，明确暗金固有附加与黄装自然附加差别。低、中、高11档roll至少测端点与中位；旧roll迁移前后不变化。
- 60秒同资源预算，包括起始MP、自然回复、固定药水时间、冷却、前摇后摇、移动停手。事件记录实际命中、实际HP损失、过量击杀、MP实付、失败施法、触发次数和有效治疗。概率项固定种子集并输出分布；不得挑一颗有利种子。

### 报告必须分栏

单体持续、6秒爆发、4目标总伤、移动战、有效治疗、生存、资源、首领免控分别报告；主要指标写清目标类型。群体场景双方打同一组怪并遵守各自合法范围，不能把四怪总伤除以黄装对一怪伤害。控制、回蓝、MF不硬折算成输出百分比。

### 必须通过的安全回归

卸装/损坏/职业不符/宿阵被压制后新施法回归；已受理有限动作按快照完成，持续来源及时失效。每根施法的触发、吸血/回蓝和控制有预算，分段不递归；换装/换同款/跨图/重登不刷新充能与冷却债务。软点不变硬点、不解锁、不增加协同来源，数量不随无限软级膨胀。

Buff无时间文本只影响展示；离开半径、来源移除或死亡后，租约按既有服务端合同失效。人物buff显示光环名、等级、来源、有效收益及同族被覆盖状态，装备不重复长篇解释。

## 8. 完成条件与责任边界

目录多样性检查、全部259暗金同级强黄低roll底线、40宿阵通道与材料验证、五变体穿脱与权限测试、四神装60秒真实场景输出、客户端卡片/buff实际展示分别给证据。静态domain过测不代替scene吞吐；编译通过不代替UI验收。研究文档没有改业务代码，没有给出虚构实测结果。
