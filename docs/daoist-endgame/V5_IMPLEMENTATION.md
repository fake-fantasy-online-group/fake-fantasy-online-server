# V5 装备、技能与成长实现

日期：2026-10-12。分支：`feature/daoist-endgame`。本文区分源码验证与实际游玩验收。

配套客户端已推送提交：`348f57897ef26fd0c021b76c816512190f7be6cf`。

## 本轮范围

- 新暗金仅使用已确认的 259 件、60 级及以下、具有当前野外掉落路径的可染色底材。其余旧暗金停止新生成；已有实例按保存的内容版本读取，不静默重写。
- 价值分布为过渡 183、小高货 54、质变 18、神装 4。实际同底材/职业数值对照为最低同级强黄色的 1.10 倍预算；这一预算比较不是总 DPS/EHP 或实战强度保证。固定主体与少量变量分开。
- MF 作用于自然掉落装备的品质与有资格底材的暗金晋升；不增加掉落数量，不改变孔数、符文数量、暗金变量，也不作用于脚本秘境奖励。归属取实际击杀责任角色，包含宠物与持续伤害来源。
- 增加分范围技能等级、元素增伤/穿抗/减免/吸收、固定等级技能触发和装备光环。保留旧平面属性意义，不把旧抗性字段偷换成百分比。
- 149 个职业战斗技能接入手动硬点上限 20、装备软等级以及至多 3 个硬点协同来源。未学技能的首次加点预览、当前/下一级效果和加点拒绝原因由服务端生成。
- 装备提升不设置玩法上的技能等级上限；数值表示或公式超出引擎可安全计算范围时明确拒绝，不回绕、不静默卡在 20。
- 人物上限 100、宠物上限 80；玩家难度层级与大秘境内部地图楼层仍是不同概念。

## 迁移与兼容

新增迁移 52–55，依赖原有 0–51：成长曲线、装备内容版本、角色技能点重置审计、触发冷却持久化。

旧角色职业战斗技能进行一次免费重置，技能点按等级减一重新计算；保留迁移前技能/剩余点快照及校验值。生活技能保留。已转职角色的旧新手战斗技能一并回收，未转职角色保留已有合法新手投入。重复执行不重复退款。

新旧客户端应与服务端配套更新；生产战斗入口要求 `endgame.growth.v5` 成功握手。未更新客户端仍可进入账号/选角流程，但不能用旧协议战斗或加点。技能读取失败、状态定义/叠加矩阵缺失、成长数据不完整时拒绝生产启动。

既有高于主人普通分经验上限的合法宠物不阻塞角色领奖；该次宠物经验为零，原等级和经验保持。超过物种或绝对 80 上限的损坏存档仍明确报错。

已受理的施法统一冻结来源属性、装备特效、状态附加量和宠物附加参数；目标条件在命中时求值，宠物概率仍逐次命中抽取。陷阱在受理、放置、触发之间不因后穿装备追增收益，并按原始与当前来源较低值结算。

跨地图或离线后无法继续跟踪来源的外部 V5 持续增益撤销；自己施放的增益保留可追踪来源并重算。避免先穿加技能装备施法、再脱装或转场永久保留高等级收益。

## 客户端与智能体

保留原生技能窗口、装备 tooltip 和既有交互入口。客户端不自行推算技能等级、协同、伤害或 MF。智能体可读取服务端技能、剩余点、装备元素统计、光环和触发冷却状态，并通过原有幂等事务执行加点。

光环复用现有素材，已核查对应 EFF 与 GSO 依赖及帧解码：钢铁、火之盾、TFX074_40。素材仅在云端资源目录，未纳入仓库。
