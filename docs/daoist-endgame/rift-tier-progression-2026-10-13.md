# 大秘境难度开放与完成时间

## 规则

难度 `tier` 为 1–150，与一局内的地图 `floorIndex` 无关。通关后的难度跳跃为：

- `tierJump = max(1, floor(remainingSeconds / 180))`
- `unlockedTier = min(150, max(previousUnlockedTier, completedTier + tierJump))`
- 剩余 0 / 179 / 180 / 359 秒均跳 1 阶；360 秒跳 2 阶；540 秒跳 3 阶。
- 已开放更高难度不会回退。15 分钟计时结束后、20 分钟硬失败前成功击杀首领仍最低跳 1 阶。
- 失败、提前离开、未取得既有通关资格的成员不解锁。既有资格检查保持不变，没有新增队长、个人当前最高难度、限时完成或领取物品门槛。

## 计时与持久化

`RiftRun.CompletedMS` 在权威首领死亡时冻结。剩余秒使用该时间与 `StartedMS`、已生效 `PenaltyMS` 计算，按秒向下取整并最低归零；结算、拾取、聊天、离线恢复均不会消耗已获得的剩余时间。

经济事务期间的死亡事件按原顺序排队，保留实际发生时间与当时在场成员，避免存档延迟跨越 3 分钟阈值或 15/20 分钟期限。首领死亡之后的玩家死亡不再倒扣本次成绩。

完成 run 是持久化权益来源，沿用既有 JSON 存档，不增加表、不改写历史数据、不需要迁移。在线自动经验事务、逐件拾取、离开以及关闭实例后的兜底领取都会把最高难度单调合并到个人 `rift.unlockedTier`；失败事务不提前发布。

旧完成记录若缺少 `CompletedMS`，不会推测额外剩余时间，只按 0 秒的最低成功奖励处理。原本已经开放的更高难度保留。

## 客户端契约

继续使用原有严格 DTO 字段，不增加协议键或修改 schema：

- `tier`：本局难度
- `floorIndex`：本局地图层次
- `maxTier`：150
- `unlockedTier`：当前角色可开启的最高难度；完成 run 落盘后快照即显示新上限
- `remainingSeconds`：进行中倒计时；完成与关闭后为冻结的完成成绩

未持久化的完成快照保持 `reward_pending`，不会提前展示新增解锁。默认可开启范围为 1 至 `unlockedTier`。

## 验证

新增 domain 与 scene 测试覆盖 0/179/180/359/360/540 秒、150 封顶、历史高阶不回退、队友/离线恢复、未领取离开、失败回滚、重复结算、罚时、旧记录，以及延迟首领事件跨硬超时和玩家死亡顺序。

所有验证均在云端运行；未对玩家数据库执行迁移或 SQL。
