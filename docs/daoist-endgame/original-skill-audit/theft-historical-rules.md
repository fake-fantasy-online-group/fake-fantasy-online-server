# 10212 偷窃术：定向历史规则核查

核查：2026-10-12。范围：QQ幻想原刺客；明确排除QQ自由幻想问答、飞升仙职技能参数。本轮仅研究，没有实现或服务器改动。

## 能确定的结论

- 原刺客确有51级偷窃技能，不能用纯伤害游龙掌替代。真实本地旧备份和当前资源都名为偷窃术；游龙掌出现在项目原SQL导入层。
- 本地旧总说明与同期网页共同支持“先有50%起、逐阶+6个百分点的偷窃判定，再按怪物掉宝规则取得物品”；这不是每次施法50–74%必出物品。
- 同一怪物失败后可以继续尝试。2006-09-12作者描述对第二只怪尝试十余次才偷到，接着花20分钟杀死那只泉灵；上下文足以区分于换怪尝试。
- 偷取成功后，该怪死亡仍可能掉出同类物品。2006-07-05与9/12由不同作者各自描述此事。实现不能无证据地把偷取当作消费死亡掉落池的唯一物品。
- 有天泉宝珠、天之峰碎片、冰冷水晶的实际偷取记录。至少不能把任务材料/任务怪统一排除。

## 对本项目的直接含义

旧备份10212的第1–5阶描述为100/103/106/109/112%伤害，与其名称、总说明和第6–10阶占位说明冲突。当前第1–5阶的50/56/62/68/74%偷窃文案修正了这个矛盾；**不能把这些阶级文案回滚成纯伤害**。maxlv为5，6–10阶存在不代表正式可升级到10阶。

不能声称“改名已经恢复”。必须有独立偷物行为，并明确处理概率门、合格物品池和重复取物生命周期。现有证据足以排除纯伤害替代、失败即永久封锁、成功就取消死亡掉落等实现。仍缺乏完整权威依据的是：**成功次数/作用域（每怪、每人还是共享）、精确合格物品池、命中与伤害语义、Boss/特殊怪资格**。它们应作为显式项目规则决定或待核实项，不能掩饰为确定官版；“只剩每怪一次一个细节”同样过度乐观。
