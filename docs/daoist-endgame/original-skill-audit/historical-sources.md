# QQ幻想早期五职业：历史来源、版本边界与恢复证据

核查日期：2026-10-12。研究范围为 QQ幻想 原五职业、非 QQ自由幻想/自由幻想手游、非飞升后的五大仙职。仅研究；本报告不授权直接覆盖数值或修改代码。

## 结论先行

1. 已找到五职业旧资料表，包含技能名称、首学等级、目标/范围/被动类型、主要伤害成长、状态和几何范围。但这些是仍可访问的历史资料站页面，不是已经验证的腾讯原始数据包，且明显保留旧版本甚至未开放设计。
2. **最重要的正式版本锚点是 2005-12-22“圣诞惊喜”公告**：震慑、煞气从旧恐惧设计改成半径150群晕，背刺、暗杀术改100%命中，冻气陷阱从60级降至45级。仓库最早导入数据的描述/等级符合这组更新，不能用陈旧静态表把它们倒退回去。
3. 当前原始SQL的单体/群体大框架与旧表大量吻合，但不能因此把SQL所有字段都称为“官方原版”。资料表与SQL存在偷窃/游龙掌、部分数值、状态、范围、描述内部冲突。应逐项归因，不能整页或整份SQL覆盖。
4. **10212 是重大机制冲突**：同期 QQ幻想 实玩资料明确存在51级偷窃技能、能取得怪物物品；SQL同位置却叫游龙掌，只描述100%至112%伤害。本次没有找到腾讯把 QQ幻想 偷窃正式改为纯伤害游龙掌的公告。不能仅改名字就宣称恢复，也不能据“最早Git里如此”认定纯伤害是官版。
5. 现有证据允许推断其职业设计世代与 **2005-12-22之后、2006年飞升前原五职业体系** 相容；不能给整份SQL确定唯一客户端版本或可靠上界。旧职业在飞升上线后仍可存在，SQL可能混入后续修改、未启用行和陈旧描述。

## 来源等级与可用性

### A. 有版本日期的发布方公告，保存在媒体镜像

- [2005-12-22 官方更新公告](https://fo.17173.com/gengxin/20051222.shtml)。页面作者标“官方”，内容为正式维护后全服升级公告，不仅是版本预告。可直接支撑三项职业变更：
  - 10029震慑、10128煞气：半径150，以自己为中心，昏迷5秒，逐级加1秒。
  - 10209背刺、10210暗杀术：命中率改为100%。
  - 10216冻气陷阱：首学改45级，去掉技能书要求。
  - 此公告还说明部分术士概率描述得到补充；未逐条刊载新值，不能凭此补造数值。
- [2005-12-17 官方转载的12/22版本预告](https://game.zol.com.cn/23/235912_all.html)。与上述改动相符，但它自己提醒以上线为准，所以证据优先级低于实际更新公告。
- [2006-06-01 1.34版更新公告](https://fo.17173.com/content/2006-06-01/20060601011842691.shtml)。明确更正意志、心境、致残、挑衅、煞气、雷霆之怒技能书的说明错误，且修复暗杀术技能书掉落问题。没有提供修正文案全文；它证明技能书文字曾出错，不能把任一旧说明一律当数值权威。
- [2006-08-03 飞升二次外测公告（8/4转载）](https://fo.17173.com/content/2006-08-04/20060804002221192.shtml)。原五职业转成飞天武者、御剑圣者、无双影者、冰火行者、圣光使者，技能全面调整；明确测试版不是最终版。这类仙职技能应排除在本次原五职业恢复之外。

腾讯旧站 fo.qq.com 根页与从新浪FAQ查到的职业链接 https://fo.qq.com/guide/character.htm 本次工具访问失败/超时；未取回任何腾讯原站技能表内容。不能把无法访问的链接包装成已核验来源。

这些页面正文是原五职业，不是飞升后技能，也不是QQ自由幻想专区。侧栏有较晚的飞升投票，因此网页整体年代不能等同于正文数据年代。正文中的煞气/震慑仍写恐惧且未作用、冻气仍60级，直接与2005-12-22正式公告冲突。这使它们适合做逐项外部交叉证据，不适合整表覆盖。

附属 historical-facts.json 以简洁事实字段整理了149条历史表记录（148战斗条目+炼丹士）：名字、等级、表中分类、可见攻击百分比/成长、几何事实和来源URL。ID由仓库名称做关联；偷窃术→10212、回避陷阱/回避魔法别名关联显式标为推断。表中“目标攻击”也用于自身增益、队友治疗，**不能简单翻译成敌方单体**。未给前置技能的行没有虚构前置。

### C. 有日期的同期玩家第一手使用记录

这些可证明当时有人实际使用某机制；精确概率仍可能来自游戏说明或个人判断，优先级低于正式公告和原始客户端。

- [2006-05-10 术士加点与使用记录](https://fo.17173.com/content/2006-05-10/1147225733.shtml?_platform=PC)：已经列出静态表漏掉的秘术：幻影，60%起始传送成功率、逐级加10%；秘术：瞬发为缩短下一技能吟唱60%、每级加10%，不是60%概率全免吟唱。魔镜记为30%起始、每级加5%，但作者写“反射”，SQL写“抵抗”，因此只佐证概率，不解决反射/抵抗机制差异。
- [2006-06-09 刺客实际加点与刷怪记录](https://fo.17173.com/content/2006-06-09/1149819653.shtml?_platform=PC)：51级偷窃，能额外获得怪物材料。文中写50%起始、每级加6%；该数值不能独自证明唯一官版概率。
- [2006-09-12 刺客偷窃宝珠记录](https://fo.17173.com/content/2006-09-12/1158046981.shtml)：明确描述对天泉怪物反复使用偷窃、获得宝珠以及游戏“没有可偷窃的物品”提示。这支持偷物机制确曾在正式服存在，不能用纯伤害技能替代。
- [2006-01-03 剑客51级群晕实用记录](https://fo.17173.com/content/2006-01-03/1136260716.shtml?_platform=PC)：半径150、5秒群晕，交叉佐证12/22改动实际落地。
- [2006-06-01 剑客使用记录](https://fo.17173.com/content/2006-06-01/1149128507.shtml?_platform=PC)：罡气的击退、真空远程、幻影单攻有同年代使用佐证；评论中个别控制秒数有出入，不能用其替代正式数据。
- [2006-07-24 开发团队采访转载](https://fo.17173.com/content/2006-07-24/1153724018.shtml?_platform=PC)：称当时不飞升不能升60以上，原职业60级以上技能还学不到。故静态表或SQL中70/80级技能“有定义”不证明当期正式服可学。本项目若要开放这些技能属于明确延展规则，不能宣称原公测即已可用。

## 对仓库导入数据的核对

本节代码事实来自 server/migrations/000000_init-31.sql 及其派生 docs/daoist-endgame/v5/skill-original-ranks.json；外部来源是上述A/B/C。初始Git导入证明“项目最早已带该数据”，不证明腾讯数据出处。

### 能共同支撑的职业身份/基本行为

- 战士：穿刺的矩形50×150、震地的120°/150扇形、流虹的80×250矩形、野战的自身圆150，以及连环/飞翔/心眼/战神等定向单目标，是静态表与导入表共同框架。
- 剑客：罡气、幻影、金缚、饮血、噬魂、封法、混沌、狮心、陨星都是目标技能，不能仅因资源含半径或形状就变成群攻。旋风、血雨、挑衅、煞气是真正群体。锁灵及火/山诀等为自身用途，需要结合文字辨识。
- 刺客：击晕/狙击/连续投掷/雷火弹/背刺/暗杀是目标技能；多重投掷为扇形、环形爆发为自身圆、五种陷阱有爆发范围。不能把“陷阱具范围”误作每次直接范围施法。
- 药师：祝福/防御/群疗/加速/瞬击/神圣庇护为友方群体；光弹/圣光为敌方目标攻击；驱魔/神威/天罚为范围伤害。治疗、复法、回春、针刺等静态表是目标技能，不能统一群体化。
- 术士：火弹/冰箭/陨石/绝对零度/虚空都是目标攻击；火球/冰爆/风焰/暴雪为范围，冰爆明确以自身为中心；火系掌握只覆盖火弹和火球，红莲之魂覆盖四个火系伤害技能。冰系相关被动的范围不能擅自扩展到全部法术。

## 偷窃术专项结论

- 机制存在：高置信。两篇2006年QQ幻想第一手记录相互支持，并与原五职业历史表一致。
- 同ID关联：高可能但仍为推断。51级、同职业、同位置与同套技能树吻合，不等于外部网页直接给过10212。
- 纯伤害游龙掌是否腾讯正式更名/重做：未证实。没有找到原游戏公告；唯一检索到的“改叫游龙掌”是2012年QQ自由幻想混杂问答，已排除为恢复依据。
- 精确偷取概率：未定。17173旧表和2006-06记录写50%+6%/级；较晚百科副本写20%+5%/级，来源/版本不明，不采纳为最终值。
- 每怪可偷次数、成功后是否禁偷、失败是否可重试、能否偷玩家、掉落池与死亡掉落独立性、任务物品资格及库存满行为：目前无完整权威规范。2006-09记录提到可重试以及偷到后仍能打落，但不能从单篇经历外推全规则。
- 建议：先保留异常证据，把10212标为需专门恢复的职业功能；不把它当正常伤害技能“已完整”，不只改名，不擅造经济掉落倍数或概率。

## 版本推断的上限

可以确定（依据公告匹配）：数据中至少若干职业行已吸收2005-12-22改动。

可以推断（有限置信）：30级秘术幻影、直接缩吟唱瞬发、30%魔镜概率与2006年5月原职业玩法相容。

不能确定：整份750行的腾讯原始包版本、所有行是否同一时间快照、70/80技能当时是否开放，以及游龙掌属于何时何产品变更。不存在足够证据把全部数据锁到单一“2005公测原版”或“1.35官版”。

恢复应以跨来源一致的职业功能为主，正式补丁保留，差异隔离。前置技能及每阶角色等级、消耗、冷却、吟唱、控制概率/持续全部精确值，目前外部没有完整核验；SQL中虽可全部导出，仍须标来源层级。不能把“在SQL里全对”当全职业原版已经恢复完成。
