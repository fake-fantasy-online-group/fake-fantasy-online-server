# 内部包分层规范

## 允许的内部依赖

下表与 `server/internal/arch/layers_test.go` 的 `allow` 表对应。
依赖按包路径前缀匹配；空列表表示不允许任何 internal 包依赖，不限制标准库。
测试夹具仍仅限测试消费，生产边界由 `testfixture_boundary_test.go` 单独校验。

| 包 | 允许的内部依赖 |
| --- | --- |
| `publiccatalog` | 无 |
| `buildinfo` | 无 |
| `testfixture` | 无 |
| `testfixture/catalog` | `domain` |
| `testfixture/monsterbehavior` | 无 |
| `domain` | 无 |
| `data` | `domain` |
| `store` | `domain` |
| `showcase` | `domain`, `store` |
| `game/event` | `domain` |
| `game/entity` | `domain`, `game/event` |
| `game/scene` | `domain`, `game/entity`, `game/event`, `game/ai`, `game/combat`, `game/spawn`, `data`, `store` |
| `game/ai` | `domain` |
| `game/combat` | `domain`, `game/entity`, `game/event` |
| `game/spawn` | `domain`, `game/entity` |
| `game/party` | `domain` |
| `game/online` | `domain` |
| `game/social` | `domain` |
| `game/trade` | `domain` |
| `wire` | 无 |
| `crypto` | 无 |
| `net` | `wire` |
| `protocol` | `domain`, `game/event`, `wire` |
| `session` | `domain`, `protocol`, `store`, `wire`, `net`, `game/scene`, `game/event`, `game/party`, `game/online`, `game/social`, `game/trade`, `data` |

`testfixture/monsterbehavior` 读取原始导入数据用于测试，只有标准库与 pgx
依赖，不允许依赖其他 internal 包。本次仅补齐已有包的精确登记，不豁免
生产代码、不增加依赖边，也不改变领域层零依赖和游戏层不得依赖协议/网络的红线。
