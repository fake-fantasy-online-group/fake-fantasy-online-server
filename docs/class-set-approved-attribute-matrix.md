## 单位和叠加

- 攻击速度+80%表示攻击速度变为180%，不是攻击间隔减少80%。
- 命中+100%表示原命中×2，不是固定+100点；最大MP+100%同理沿原属性计算顺序。
- 暴击率、暴击伤害使用百分点；物理暴伤+15使原200%变215%，不作用法术暴伤。
- 物理技能伤害只影响相应技能，不默默提高普攻。刺客陷阱额外涵盖自置陷阱；同一次物理陷阱伤害不能叠两次18%。
- 8件属性进入V1既有装备伤害/减伤桶，新增装备减伤受原45%桶上限约束；不能把后来确认的独立光环减伤/不羁重复加入。
- 治疗量只放大一次名义治疗；复制和附加治疗遵已确认无递归规则，不对同一份治疗重复×1.15。

## 五光环

范围恢复V1的300；自身与同队范围内玩家收益，同职业不叠加，不新增5人上限。原500ms刷新/1000ms视觉租期不变。

右侧显示名依次为勇气之刃、胜利王座、夜色拥抱、哲理之石、信仰之翼。视觉协议key仍是“套装光环·职业”，显示名不能破坏资源查找。

矩阵是验收输入，不表示尚在开发的迁移94已验证或已发布。云端最终日志及实际本地运行版本需分别确认。
