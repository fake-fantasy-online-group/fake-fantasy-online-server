# 九类灵加工与实例保留

范围：鞋、拳、羽、衣、项、面、帽、法宝、武器。戒灵及缺少条件/附加属性的21个后期衣灵外形不启用。原来的固定灵存档不做批量转换。

## 服务端契约

沿用 endgame JSON 通道，能力 `endgame.spirit.v1`。未协商客户端不接收新字段，旧融合入口不能消耗动态灵。`hello`、`spirit.open` 返回九种定义和92个支持的外形道具 ID。定义包含真实NPC模板、名称、脚本、地图、元神、分离符及铜币费用。

NPC操作 `spirit.preview/unseal/process/rollback/reset` 使用两个实际背包选择 `spiritItem` 与 `spiritMaterial`；选择包含 tab、页内 slot、itemId、已有实例的十进制 uid。每次执行重新校验对应NPC、地图、距离及材料。预览不随机、不消耗。

融合/分离/外形使用 `spirit.fuse/separate/appearance`，spiritItem 指消耗的道具，targetUid 指背包或穿戴装备。写操作沿用 requestId、expectedRevision、原子事务与持久收据，不新增原生 opcode。

## 加工语义

属性按原始12项权重不放回抽取。鞋灵固定四条，其他2/3/4条分别60/35/5%。每条每次独立抽10—20；恰为20即完美，无第二次隐藏判定。

为落实“每条20永久保留”同时避免归元无限叠加，每条属性独立保留15个加工槽。20占永久槽，普通10—19占普通槽。回退仅移除最近一次的普通结果，归元清除普通槽；永久槽始终占用，总值不超过300。各条次数可能不同，继续加工只填未满的条目。界面使用 CanProcess，不能以共享Level=15判断全部满级。这是根据用户规则确定的实现语义，不声称原版客户端已有相同内部模型。

解封2元神；加工前等级0—4/5—9/10—14分别消耗2/4/5元神；回退1；归元200。加工费用八类100银、法宝50银（分别100000/50000铜）。等级零可重解封；已有加工不可重解封。

## 所有权与保存

新灵使用 instance_kind=4，值类型固定数组存档；融合时原UID和完整状态嵌入装备，分离返回原实例。新灵不与普通堆栈合并。附加外形独立归装备所有，分离不清除装备自身属性、强化、卡片、威能或外形附加属性。

迁移120添加灵状态及装备关联表，121添加22条黄金/暗黑配方路径（20产物，含拳灵两种黄金证兼容）。保留72条原配方及费用；新兑换未臆造额外费用。暗黑升级消耗黄金外形与暗黑证，不二次扣黄金外形制作材料。

## 外形

92条由原始 avatarcheck/avatararmdesc/equip_extra/souleffect 与公开规则对应，包含184条附加属性、82个跟随特效、10种武器模型。门槛采用已确认的 >=。只有装备所附动态灵达到条件才可使用，之后外形及附加属性不依赖灵仍然存在。
