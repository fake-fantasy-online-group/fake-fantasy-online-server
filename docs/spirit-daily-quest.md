# 灵元寻踪（每日灵元委托）

- 九位灵仙子共用任务号 `1900030100`；戒灵不加入。
- 每个角色、北京时间自然日、九 NPC 合计完成一次。不是账号级限制。
- 从实际地图刷怪点筛出非副本/非试炼 BOSS，按角色 ID 和日期稳定抽取三种不同 BOSS，每种击杀一次。重复打开、放弃后重接、换 NPC 不会刷新当天的目标。
- 接取时将三种目标、展示位置、日期和奖励灵种完整保存到 `character_quests.spirit_daily`。目标采用值类型，快照不会引用共享的可变数据。
- 同时只存在一个该任务；领取奖励必须返回接任务的仙子。每次奖励对应元神 300 个。
- 已接未完成的任务跨日保留目标与进度，交付消耗交付当天的次数。当天完成后不能再接；次日可重新接取。
- 击杀沿用现有任务归属：补刀玩家，宠物归主人；不是新增全队共享规则。只认公开世界的真实 BOSS 刷怪实体，副本、洞天、试炼、召唤物不计。某 BOSS 在多个公开地图刷新时，任一真实刷点击杀都计入。
- 接取、放弃、交付采用现有 endgame revision CAS / receipt / snapshot 提交。元神入包和当日完成标记同事务；背包不足、数据库失败、重复点击不会扣除次数或重复给奖励。
- NPC候选列表、任务详情、任务进度、接受和提交均复用原生任务协议。客户端仅补未知任务号的人类可读标题“灵元寻踪”。

## 部署前置

先执行 `000123_20261028_spirit_daily.sql`。完整初始化包含同体 `000000_init-123.sql`。此次只新增 JSONB 列，不重写角色既有任务。
