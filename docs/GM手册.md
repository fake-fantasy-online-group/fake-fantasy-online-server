# GM 命令手册

本文只记录当前服务端 `server/internal/session/gm.go` 白名单接受的命令。命令通过正式客户端游戏内聊天发送；网页工作台只生成并复制文本，不会替玩家执行命令。

## 使用条件

账号的 `gm_level` 至少为 `1`，并且角色已进入游戏世界。权限属于账号，在登录时读取；修改等级后，必须退出账号并重新登录才会刷新。所有 GM 命令都要求当前 GM 角色在线，即使命令操作另一名玩家或账号也一样。

在游戏聊天输入框发送以 `/` 开头的命令。命令名不区分大小写，每条最多 512 字节。所有命令都能加 `gm` 前缀，例如 `/addexp 100` 和 `/gm addexp 100` 等效。

`/help`、`/gmhelp`、`/gm` 和 `/gm help` 均显示服务端帮助。传送命令另有 `/teleport` 别名。识别的命令执行结果以服务端文本消息返回；服务端同时记录 GM 命令审计日志。

## 权限等级

| `gm_level` | 名称 | 权限范围 |
| ---: | --- | --- |
| 0 | PLAYER | 无 GM 权限 |
| 1 | APP | 当前角色的资源、物品、战斗状态、传送、特效和查询 |
| 2 | WIZARD | APP 权限；查询、发奖、禁言在线角色，以及发送公告 |
| 3 | ARCH | WIZARD 权限；踢出在线角色 |
| 4 | ADMIN | ARCH 权限；封禁和解封账号 |

权限逐级包含。所有命令最终都由服务端检查权限，客户端显示什么入口不影响权限判断。

## 当前命令

| 命令 | 最低等级 | 作用 |
| --- | --- | --- |
| `/gm help` | APP | 显示服务端 GM 命令列表 |
| `/effect <技能ID> [self\|pet]` | APP | 播放该技能一级定义中已核实的实体特效，默认目标为自己 |
| `/ownersync` | APP | 将出战宠物实体的当前主人关系重新广播 |
| `/addexp <经验>` | APP | 给自己增加经验 |
| `/addmoney <铜币>`、`/addgold <金币>`、`/addsilver <银币>`、`/addhonor <名誉>` | APP | 增加自己的对应资源 |
| `/item <物品ID> [数量]` | APP | 给自己的背包发物品 |
| `/takemoney <铜币>`、`/takegold <金币>`、`/takesilver <银币>`、`/takehonor <名誉>` | APP | 扣除自己的对应资源 |
| `/takeitem <物品ID> [数量]` | APP | 从自己的背包扣除物品 |
| `/max` | APP | 补满生命与法力；死亡时在原地复活 |
| `/god [on\|off\|status]` | APP | 查询、开启或关闭无敌状态 |
| `/oneshot [on\|off\|status]` | APP | 查询、开启或关闭持续生效的秒杀状态 |
| `/goto <地图ID> [X Y]` | APP | 传送到地图安全落点或指定坐标 |
| `/where` | APP | 查询当前地图、坐标和场景实例 |
| `/online` | APP | 查询在线人数及最多 20 名在线角色摘要 |
| `/inspect <角色名>` | WIZARD | 查询一名在线角色的状态、背包占用和位置 |
| `/givemoney <角色名> <铜币>` | WIZARD | 给在线角色增加铜币 |
| `/giveitem <角色名> <物品ID> [数量]` | WIZARD | 给在线角色发物品 |
| `/mute <角色名> <分钟>`、`/unmute <角色名>` | WIZARD | 禁言或解除在线角色的聊天 |
| `/announce <内容>` | WIZARD | 向所有在线角色发送系统公告 |
| `/kick <角色名>` | ARCH | 断开在线角色连接 |
| `/ban <角色名> [分钟]`、`/unban <角色名>` | ADMIN | 永久或限时封禁、解封角色所属账号 |

## 参数和行为

- 经验数量为 `1` 到 `1,000,000,000`；货币和名誉每次增减为 `1` 到 `1,000,000,000,000`。扣除时资源不足会整条失败，不会部分扣除；增加时会检查溢出。
- 物品数量省略时默认为 `1`，上限 `10,000`。物品 ID 必须是正数，可用十进制或 `0x` 十六进制。物品必须存在；背包空间不足或数量不足时不会部分修改。`/takeitem` 只移除背包物品，不会卸下已穿戴装备；宠物载体物品不能用该命令删除。
- `/effect` 的技能 ID 必须对应一级定义含有已核实实体特效的技能；指定 `pet` 时必须有出战宠物。`/ownersync` 也要求有出战宠物。
- `/god` 与 `/oneshot` 不带参数时查询状态。`/god on` 会复活并补满生命（若已死亡），并清除有害状态；开启后免疫直接伤害、持续伤害、反伤及新有害状态。`/oneshot on` 会在开启期间对每次真实有效的攻击命中触发秒杀；攻击未命中或伤害原本为零时不会击杀目标。该状态持续到执行 `/oneshot off` 或退出登录。两种状态各自开关，切图保留，退出登录后清除，不持久化。
- `/goto` 地图 ID 必须为正数，且地图要有服务端确认的安全落点；`X`、`Y` 必须同时提供且为非负整数。没有安全落点的地图会拒绝传送，即使手动提供坐标也是如此。
- `/where`、`/online` 不修改角色。`/online` 最多列出 20 个名字、等级和地图，其余只计入总人数。
- `/inspect`、`/givemoney`、`/giveitem`、`/mute`、`/unmute` 和 `/kick` 使用角色名，目标必须在线，可位于其他地图。发奖通过目标当前场景处理。永久 `/ban` 与 `/unban` 可使用数据库中存在的离线角色名；限时封禁要求目标在线。封禁作用于整个账号并断开该账号所有在线角色，不能封禁或解封自己的 GM 账号；不能踢出自己。
- 禁言时长为 `1` 到 `10,080` 分钟（七天），只在当前在线会话生效，断线后清除。被禁言者不能发送聊天。
- 公告内容为 `1` 到 `300` 字节，服务端会加上 `【系统公告】` 前缀并发送给当时全部在线角色。
- 封禁时长为 `1` 到 `525,600` 分钟；省略分钟为永久封禁。到期后账号可重新登录；解封不会替玩家自动登录。

## 修改账号 GM 等级

可在“幻想数据库”网页的“GM 手册”页展开“账号权限”面板。按账号名、角色名或账号 ID 搜索，检查账号和角色后选择等级并确认保存。等级范围为 `0` 至 `4`；保存使用当前等级作为预期值，若期间已有其他修改会提示冲突，刷新后再操作。保存后必须让玩家完整退出账号并重新登录。

也可以在有权限的 PostgreSQL 管理会话中直接更新 `accounts.gm_level`，但网页面板是项目提供的管理入口。数据库网页不会执行 GM 游戏命令。

## 失败时

常见原因包括：账号不是 GM 或等级不足、角色尚未进入游戏、参数格式或范围不正确、目标不在线、物品数据不存在、背包空间不足、扣除资源不足、地图没有已验证的安全落点、场景命令超时。失败原因会通过服务端文本返回；识别到的命令及其结果也会写入服务端的 GM 命令审计日志。

网页工作台当前不提供 `/effect` 和 `/ownersync` 的命令表单；这两条命令仍可在游戏聊天中直接输入。
