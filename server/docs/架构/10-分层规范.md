# 服务端分层规范

## 1. 内部依赖表

可执行约束在 `internal/arch/layers_test.go` 的 `allow` 表。新包必须同时登记说明和测试表，测试辅助文件不计生产依赖。

- `domain`：零内部依赖。
- `data`、`store`：只依赖 `domain`。
- `game/event`、`game/ai`、`game/party`、`game/online`、`game/social`、`game/trade`：只依赖 `domain`。
- `game/entity`：`domain`、`game/event`。
- `game/spawn`：`domain`、`game/entity`。
- `game/combat`：`domain`、`game/entity`、`game/event`。
- `game/scene`：`domain`、`game/entity`、`game/event`、`game/ai`、`game/combat`、`game/spawn`、`data`、`store`。
- `wire`、`crypto`：零内部依赖；`net`只依赖`wire`。
- `protocol`：`domain`、`game/event`、`wire`。
- `session`：`domain`、`protocol`、`store`、`wire`、`net`、`game/scene`、`game/event`、`game/party`、`game/online`、`game/social`、`game/trade`、`data`。
- `showcase`：`domain`、`store`。仅为显式离线维护命令编排物品工厂、快照保护及原子保存；不接网络、不依赖场景或会话，也不得成为在线游戏层的依赖。

## 2. 不可越过的边界

游戏层不得引用协议或网络；domain不得依赖其他内部包。展示工具不绕过生产物品工厂与持久化不变量。CLI 的配置与静态资源加载在 `cmd/showcase-grant`，`showcase` 核心只消费已准备的值与存储接口。
