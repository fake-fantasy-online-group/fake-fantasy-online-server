# 参考资料调研

本项目为学习项目，参考了吊想，并结合公开游戏资料研究服务端的领域划分与数据建模。

## 资料来源与用途

| 来源 | 调研范围 | 使用方式 |
| --- | --- | --- |
| [腾讯《幻想》资料站](https://fo.qq.com/) | 职业、宠物、家族、生活技能、装备与社交系统 | 了解玩法概念与交互关系；历史页面索引见 [sources.md](sources.md) |
| [腾讯《QQ自由幻想》资料站](https://ffo.qq.com/) | 职业和历史玩法说明 | 对照术语；不同游戏、时期的规则不直接混用 |
| [纷纷兔](https://fenfentu.org/) | 物品、装备、宠物、经验、合成等结构化资料 | 比较字段与规则；同名数据不视为版本一致 |
| [QQ幻想吧](https://tieba.baidu.com/f?kw=qq幻想) | 玩家对战斗、成长、命中等机制的讨论 | 作为待核实线索，不直接当作权威数值 |

## 调研方法

- 将资料拆成实体、字段、取值范围、前置条件与状态变化，避免只照搬页面展示值。
- 区分基础属性、装备加成、百分比修正与最终战斗结果，分别建模。
- 宠物等级成长、可分配点数、已分配点数、道具使用次数分别记录，避免混用概念。
- 区分官方描述、第三方汇总与玩家经验；资料矛盾时保留来源和版本差异，不用猜测补齐。
- 时间型效果要区分在线剩余时长与绝对到期时刻；服务端负责保存与计算，界面只负责展示。

本目录保留参考来源和项目自己的调研摘要，不包含客户端逆向过程、抓包、网页全文、论坛账号资料或工作进度。资料与商标归各自权利人所有，不由本项目重新授权。
